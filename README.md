# StroyApp 🎉

Мобильное приложение для организации тоя в Казахстане: банкетные залы и рестораны, тамада, артисты, декор, кейтеринг, фото и видео — поиск, заявки и переписка в одном месте.

> **Статус:** бэк в проде (`https://api.stroyapp.kz`), приложение 1.0 готовится к публикации: тестовые сборки в Google Play и TestFlight.

## ✨ Функционал

### Для гостей (без регистрации)
- 🔍 Поиск залов и исполнителей по категориям с фильтрами (город, дата, число гостей, цена, удобства)
- 📍 Сортировка по близости к текущей геолокации
- 🏛 Просмотр деталей зала: фото, цены, описание, удобства, отзывы
- 📅 Занятость зала и исполнителя на выбранную дату
- 🌗 Светлая и тёмная темы
- 🌐 Русский и казахский языки

### Для зарегистрированных клиентов
- ❤️ Избранное
- 💬 Чат с владельцем зала или исполнителем (даже до подачи заявки)
- 📨 Заявки на бронирование
- ⭐ Отзывы после посещения

### Для владельцев и исполнителей
- 🏢 Заведение с несколькими залами или объявление исполнителя
- 📷 Загрузка фотографий
- 📨 Входящие заявки (подтвердить / отклонить)
- 📅 Календарь занятости зала (дата занята после подтверждения заявки)
- 💬 Переписка с клиентами
- 🗑 Удаление аккаунта в приложении

## 🛠 Стек

### Бэкенд (`stroyapp-back/`)
- **Python 3.12** + **FastAPI**
- **PostgreSQL 16** через `asyncpg`
- JWT аутентификация
- Inline f-string SQL через `fit_to_sql` (без ORM)
- Self-applying миграции при старте

### Фронтенд (`stroyapp-front/`)
- **React Native 0.86** + **Expo SDK 57**
- **TypeScript**
- **expo-router** — экраны-файлы, системные вкладки и шапки
- Свои компоненты интерфейса, системный шрифт, светлая и тёмная тема
- **Zustand** — state management
- **i18next** — мультиязычность
- **Axios** — HTTP клиент

## 🚀 Локальный запуск

### Требования
- Python 3.12
- Node.js 20+
- PostgreSQL 16
- Dev-сборка приложения на смартфоне (профиль `development` в EAS) или браузер: Expo Go с этим проектом не работает

### Подготовка БД

В PostgreSQL создай юзера и базу:

```sql
CREATE USER stroyapp_user WITH PASSWORD 'твой_пароль';
CREATE DATABASE stroyapp OWNER stroyapp_user;
```

Все таблицы создадутся автоматически при первом запуске бэка.

### Запуск бэка

```powershell
cd stroyapp-back

# Создать виртуальное окружение
python -m venv .venv
.\.venv\Scripts\Activate.ps1

# Установить зависимости
pip install -r requirements.txt

# Создать .env на основе примера
Copy-Item .env.example .env
# Отредактируй .env: пароль БД, JWT_SECRET (32+ случайных символа)

# Запустить
python main.py
```

Бэк поднимется на `http://localhost:4000`. Swagger: `http://localhost:4000/docs`.

### Запуск фронта

```powershell
cd stroyapp-front

npm install

# Локальный бэк вместо прода: адрес задаётся переменной окружения
$env:EXPO_PUBLIC_API_URL = "http://ВАШ_IP:4000"

# Запустить Expo (dev-сборка на смартфоне) или веб-превью
npm start
npm run web
```

Откроется Metro Bundler. В dev-сборке приложения отсканируй QR-код. Смартфон и компьютер должны быть **в одной WiFi сети**. Подробности — в `stroyapp-front/README.md`.

Узнать IP в PowerShell: `ipconfig` → искать `IPv4 Address` (обычно `192.168.x.x`).

## 🧪 Тестовый OTP

В режиме разработки SMS не отправляются. Код для входа всегда **`0000`**.

Чтобы включить настоящие SMS — настроить SMS-провайдера в `libs/sms.py` (например Mobizon).
