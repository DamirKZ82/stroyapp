# Лендинг СтройАпп

Статичная страница без сборки: `index.html`, `styles.css`, `main.js`, `logo.svg`.
Открыть локально — просто `index.html` в браузере.

## Что заменить перед публикацией

- **Ссылки на сторы** — `STORE_LINKS` в `main.js`. Пока пусто, кнопки показывают «скоро».
- **Цены тарифов** — в `index.html`, раздел `#pricing`: сейчас «— ₸».
- **Куда уходят заявки партнёров** — `PARTNER_EMAIL` в `main.js` (форма открывает почту с готовым письмом).

## Где разместить

Например, отдельный `server` в `nginx/nginx.conf` для `stroyapp.kz` с `root` на эту папку
(примонтировать её в контейнер nginx). Сейчас nginx обслуживает только `api.stroyapp.kz`.
